# 利率更新用データ領域（準備段階）

現行公開アプリは、利率がHTML内部に埋め込まれた形式です。**このフォルダーはまだ公開アプリには接続されていません。**

- `catalog.json`：117版に含まれる13商品と参照先。URL到達だけで正しい利率とは判断しない
- `proposed.json`：自動抽出候補用。初期値は空。未確認値の混入を防ぐ
- `validate_rates.py`：通貨・期間・条件ID・重複等の形式チェック（出典内容との真正性の判定ではない）

今後の公開条件：商品ID・通貨・プラン/年齢/性別/保証期間の固有ID・利率・適用開始/終了・直接の公式出典・検証日時が全て一致し、公式情報との突合に成功した場合に限る。確認待ちは非公開にし、過去利率を現行と偽らない。

必要な残作業：公式サイト別の抽出パーサー・出典突合テスト・承認済みJSONをアプリで参照する実装・公開検証。GitHub Actionsの単なるスケジュール登録は自動更新完成を意味しない。
